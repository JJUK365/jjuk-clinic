# 쭉한의원 홈페이지

공개 홈페이지: https://jjuk365.github.io/jjuk-clinic/

“다시, 편안하게. 아픔 없이 쭉.”을 중심으로 구성한 반응형 홈페이지입니다. 기본 색상은 라임, 짙은 초록, 아이보리입니다. 의료진 상세 약력, 진료 안내, 소개 팝업, 예약 절차 미리보기가 동작합니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

표시되는 로컬 주소로 접속합니다. `index.html`을 파일로 직접 열면 ES 모듈이 제한되므로 개발 서버를 이용합니다.

```sh
npm run check
npm test
npm run build
```

`dist/`가 배포 결과입니다. 경로는 상대경로이며, GitHub 프로젝트 Pages의 저장소 이름 하위 경로에서도 동작합니다. 진료 상세 화면은 `#pain/back`처럼 해시 경로를 사용하므로 새로고침에도 별도 서버 설정이 필요 없습니다.

서버 없이 열어볼 수 있는 단일 HTML은 `npm run preview:file`로 만듭니다. `preview.html`에 현재 코드, 스타일, 로고, 사진이 함께 담깁니다. 다른 경로로 내보내려면 `npm run preview:file -- /원하는/경로/홈페이지.html`을 사용합니다. 실제 예약 서버와 외부 글꼴·영상 주소는 인터넷 연결이 필요합니다.

## GitHub Pages

1. 저장소 기본 브랜치를 `main`으로 지정하고 코드를 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
3. **Actions → Check and deploy GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 push할 때마다 검사와 배포가 자동 실행됩니다.
4. 배포 작업에 표시되는 URL에서 홈페이지를 확인합니다.

GitHub Free에서는 공개 저장소에 Pages를 사용할 수 있습니다. 비공개 저장소의 Pages 지원은 계정 플랜에 따라 달라집니다. 공개 저장소에는 환자 정보, 개인 이력서 원문, 비밀키를 올리지 마세요.

## 내용과 색상 바꾸기

`src/clinic-config.js`에서 전화, 주소, 카카오 채널, 운영시간, 비급여, 영상, 색상을 수정합니다. 개원 전 미확정 정보는 빈 값으로 두었습니다. `theme`은 `lime`, `orange`, `sky` 중 하나입니다. 세 색의 동일 구성 비교는 `/docs/colors.html`에서 볼 수 있습니다. 비교 페이지는 검색을 차단하며 환자용 메뉴에 노출하지 않습니다.

브랜드 색상은 `assets/theme.css`, 전체 레이아웃은 `assets/site.css`, 본문과 약력은 `src/app.js`에 있습니다. 확정 조합은 라임 `#C3E85A`, 짙은 초록 `#243D2B`, 아이보리 `#F7F8EF`입니다. 라임은 강조용이고 작은 글씨에는 짙은 초록을 사용합니다.

슬로건은 “진심 어린 건강 관리, 쭉.”입니다. 흰 배경·검은 로고 파일은 `assets/brand/jjuk-wordmark-black-on-white.png`에 마련했습니다.

앞서 제작한 둥근 텍스트 로고를 `assets/brand/jjuk-wordmark.png`로 정리했습니다. 투명 이미지의 형태를 CSS 마스크로 사용해 상단·첫 화면·소개 팝업·푸터의 로고를 같은 형태와 정확한 지정색으로 표시합니다. `/docs/brand.html`에서 최종 컬러 적용안을 볼 수 있습니다.

## 영상 연결

현재 실제 영상 파일은 제공되지 않아 움직이는 브랜드 화면을 표시합니다. 영상이 준비되면 `assets/clinic.mp4`에 넣고 `video: 'assets/clinic.mp4'`로 지정하거나 HTTPS 영상 주소를 입력합니다. 첫 화면은 음소거·반복 재생이며, 팝업에서는 재생 컨트롤을 사용할 수 있습니다. 일시정지 버튼, 화면 밖 재생 중단, 동작 줄이기 설정을 지원합니다. 영상 로딩 실패 시 브랜드 화면으로 돌아갑니다.

## 실제 예약 접수

현재는 **예약 절차 미리보기**입니다. 이름·전화는 예시값으로 고정되어 있고, 예약 요청은 저장하거나 전송하지 않습니다. 날짜와 시간 선택 기능만 작동합니다.

GitHub Pages는 정적 호스팅이므로 예약을 받으려면 별도의 HTTPS 접수 서버가 필요합니다. `booking.enabled`, `booking.endpoint`, `booking.replyHours`, `booking.privacyText`, 대표전화가 모두 설정돼야 실제 전송으로 바뀝니다. 서버는 이 사이트의 출처에 대해 CORS를 허용하고, `POST` JSON 요청을 처리해야 합니다. 성공 시 2xx, 실패 시 오류 응답을 반환합니다.

서버가 받는 필드는 `patient`, `phone`, `date`, `time`(HH:mm), `department`, `consent`이며 자동차보험 선택 시 `insurance`, `accidentDate`가 추가됩니다. 정확한 필드 이름은 `src/app.js`의 폼 `name` 속성을 함께 확인하세요. 서버에서 입력·영업시간·동의·중복 요청을 검증하고 접수 기록과 접근 권한을 관리해야 합니다. 브라우저의 시간 선택은 재고 예약이나 예약 확정을 의미하지 않습니다. 요청 후 담당자가 연락해 확정하는 흐름입니다.

예약 서버의 키를 프런트엔드 설정에 넣으면 공개됩니다. 키는 서버 쪽에서 관리해야 합니다.

## 공개 전 상태

개원 장소, 대표전화, 사업자 정보, 실제 운영시간, 비용은 확정 후 설정합니다. 현재 `index.html`은 `noindex, nofollow`로 검색 노출을 막고 있습니다. 정보 확정 후 필요에 따라 변경하세요. Google Fonts를 이용하며 로딩 실패 시 시스템 한글 서체로 표시합니다.

사진·성명·브랜드는 쭉한의원 홈페이지에 사용하도록 제공된 자료입니다. 제3자의 재사용을 허용하는 오픈소스 라이선스는 부여하지 않았습니다.
